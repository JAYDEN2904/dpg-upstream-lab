# Contribution Guide

Thank you for contributing to this classroom repository.

## Rules

1. Create or claim an issue before making a change.
2. Address only one issue in each pull request.
3. Create a separate branch for your work.
4. Use a meaningful branch name.
5. Use a clear commit message.
6. Explain the problem and change in the pull request.
7. Ask another group to review the change.
8. Respond respectfully to feedback.
9. Do not merge your own pull request.
10. Do not include personal, confidential, or sensitive information.
